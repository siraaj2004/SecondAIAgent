# Second AI Agent

A completely separate project from the Relationship AI Keyboard.

This folder is the isolated workspace for the second agent. Everything for
this agent — code, config, tests, and docs — lives in here and nowhere else.

See `PROJECT.md` for the project details, isolation rules, and next steps.

## Structure

```
second-ai-agent/
  PROJECT.md        # main project file
  README.md
  .env.example      # copy to .env and fill in this project's own keys
  .gitignore
  requirements.txt
  src/
    main.py         # starter entry point (placeholder)
  tests/
  docs/
```

## Run the starter

```bash
cd ~/workspace/second-ai-agent
python3 src/main.py
```
